Web-Based Online Auction Platform

Sistem Lelang Digital

Aplikasi web ini adalah platform pelelangan daring (online auction) yang memfasilitasi transaksi jual beli dengan sistem penawaran (bidding). Proyek ini dirancang secara komprehensif mulai dari manajemen data (CRUD) hingga pengaturan hak akses pengguna (Role-Based Access Control) untuk memastikan proses lelang berjalan secara efisien, aman, dan terstruktur.

Lihat Background & Objective
  • Mendigitalisasi proses lelang konvensional menjadi platform daring yang user-friendly.
  • Merancang sistem pengelolaan data lelang (barang, penawaran, dan pengguna) yang efisien menggunakan prinsip CRUD (Create, Read, Update, Delete).
  • Menyediakan antarmuka yang intuitif bagi berbagai jenis pengguna yang terlibat dalam ekosistem lelang.
Lihat Detail Implementasi (Key Features)

1. Role-Based Access Control & User Management

  • Sentralisasi Pembuatan Akun: Pembuatan akun hanya dapat diinisiasi oleh Admin untuk menjaga keamanan platform.
  • Force Profile Completion: Saat login pertama kali, sistem secara otomatis memaksa Penjual dan Pembeli untuk melengkapi profil esensial sebelum dapat mengakses fitur utama.

2. Sistem Manajemen Barang Lelang (Penjual)

  • Create: Modul pendaftaran barang dengan parameter spesifik seperti kategori, harga awal, kelipatan penawaran, batas waktu lelang, dan unggahan foto.
  • Read: Tampilan dasbor khusus untuk memantau status barang yang sedang dilelang.
  • Update & Delete: Fleksibilitas untuk merevisi detail barang atau menghapus barang dari basis data.

3. Mekanisme Penawaran / Bidding System (Pembeli)

  • Katalog Dinamis: Eksplorasi grid katalog barang lelang terbaru beserta status tenggat waktunya.
  • Detail & Validasi Penawaran: Pada halaman detail barang, pembeli dapat melihat tawaran tertinggi saat ini, lalu memasukkan nominal tawaran baru.
Hasil & Dampak: Proyek ini berhasil menghasilkan sistem informasi berbasis web yang fungsional dan responsif, mendemonstrasikan pemahaman yang kuat terkait arsitektur client-server, manipulasi database relasional, dan pengamanan alur akses pengguna.

Recreate Website Adidas

Reverse Engineering & Fullstack Implementation

Proyek pembelajaran komprehensif yang bertujuan untuk meniru dan membangun ulang (recreate) antarmuka serta fungsionalitas utama dari website resmi Adidas. Proyek ini dilakukan dengan metode reverse engineering melalui Inspect Element untuk memahami struktur UI/UX, yang kemudian diimplementasikan dari nol menggunakan teknologi modern.

Lihat Detail Implementasi
  • Melakukan analisis struktur DOM dan CSS dari website asli Adidas menggunakan browser developer tools untuk mencapai tingkat akurasi visual yang tinggi.
  • Mengembangkan bagian frontend yang interaktif dan responsif menggunakan React, JavaScript, HTML, CSS, dan Bootstrap.
  • Membangun arsitektur backend yang tangguh menggunakan framework Laravel untuk menangani manajemen data dan logika bisnis.
  • Mengimplementasikan fitur Role-Based Access Control (RBAC) untuk memisahkan hak akses antara pengunjung biasa dan administrator sistem.
Pencapaian: Berhasil menghasilkan replika fungsional dengan antarmuka yang mirip dengan aslinya, serta mendapatkan pemahaman mendalam tentang integrasi React dengan Laravel.
